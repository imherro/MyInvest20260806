# 市场研究真实数据源

当前14/14项代理快照均已真实接通：F1、F2、F3、F4、L1、L2、L3、L4、L5、B1、B2、B3、B4、B5。F/L/B评分、历史PIT和校准仍待完成。

## F1 盈利趋势——第一阶段已披露样本盈利同比代理

- 提供方/API：Tushare Pro `fina_indicator_vip`，单次按最近已结束季度请求；字段严格为 `ts_code,ann_date,end_date,netprofit_yoy`。
- 当前季度：以信息截止日当日或之前最近结束的自然季度为 `targetPeriod`；2026-08-17对应2026-06-30。
- 公告边界：只使用 `end_date` 等于目标季度且 `ann_date` 不晚于信息截止日的记录；公告日期缺失的记录因无法证明当时已公开而排除，非空但非法日期使整批失败。
- 公司归并：同公司同公告日的重复记录中，缺失副本与唯一合法值合并为该合法值；两个不同合法值冲突时失败。每家公司只保留截至信息截止日公告日期最大的一条记录。
- 计算：对最新记录中非空且有限的 `netprofit_yoy` 计算简单中位数；空值不视为0，负数、0和正数均合法。

F1当前只是最新已结束季度中、截至信息截止日已披露公司的归母净利润同比中位数代理，不是全A总利润增长率或完整盈利周期；未处理完整财报修订PIT、历史趋势和样本选择偏差，不计算评分。

## F2 盈利扩散与质量——第一阶段已披露样本盈利扩散代理

F2与F1完全共享同一次 `fina_indicator_vip` 请求、公告日边界和公司最新记录样本，不增加API或字段。对F1有值样本中 `netprofit_yoy > 0` 的公司计为正增长，计算“正增长家数 / 有值家数”；0、负数不计为正增长，空值不进入分母。当前只覆盖盈利扩散，不代表盈利质量，也不计算评分。

## F3 股东回报 / 股权融资——第一阶段现金分红股东回报代理

F3直接复用B2同一 `daily_basic` 有值样本的市值加权TTM股息率结果，不增加请求、字段或计算函数。当前只覆盖现金分红，尚未接入股票回购，也未扣除IPO、增发等股权融资，因此不是完整的股东回报/股权融资指标，不计算评分。

阶段04F的F3月度历史不增加数据源或网络请求，逐点复用B2已验证的 Tushare Pro `daily_basic.dv_ttm` 与 `total_mv` 形成的市值加权TTM股息率、样本数量和覆盖率。它仍只表示现金分红代理，不包含回购或股权融资。

## F4 长期资金——第一阶段沪深300ETF资金池规模代理

- `etf_basic`：按 `index_code=000300.SH`、`list_status=L` 获取目标ETF，只纳入F4数据日当时已上市且上市日期可验证的基金。
- `etf_share_size`：严格在早于信息截止日的最近共同交易日请求一次，汇总目标ETF合法 `total_size`；单位从万元换算为万亿元。
- T+1边界：ETF规模数据次日约8:30更新，因此 `release` 为数据交易日后一个自然日，且不得晚于信息截止日。

F4只表示沪深300ETF被动权益资金池的绝对规模，不代表全部长期资金、养老金、险资、社保基金、全部公募权益资金或资金净流入；基础列表也不是完整历史PIT股票池，不计算趋势、分位或评分。

## L1 利率与实际利率——第一阶段名义资金利率代理

- 提供方：Tushare Pro
- API：`shibor`
- 字段：`date,on,1w,3m,1y`
- 日期：在信息截止日前30个自然日内选择不晚于 `asOf` 的最近唯一合法记录；`period` 与 `release` 均为该SHIBOR日期。
- 计算：展示隔夜、1周、3月、1年利率，并计算描述性的 `1Y - ON` 期限差。

SHIBOR属于名义银行间资金利率，官方在每个交易日11:00发布。本系统当前只支持日终信息截止，不回答当日11:00之前的日内PIT问题。任务03D尚未接入CPI或通胀预期，因此不构成完整实际利率指标，也不计算历史分位、趋势或评分。

## B3 PE/PB与估值分化

- 提供方：Tushare Pro
- 端点：`https://api.tushare.pro`
- API：`index_dailybasic`
- 指数：沪深300 `000300.SH`、创业板指 `399006.SZ`
- 字段：`ts_code,trade_date,pe_ttm,pb,turnover_rate,turnover_rate_f`
- 算法：在45个自然日窗口内，选择不晚于信息截止日且两只指数均有数据的最近共同交易日。

阶段04A另以相同 `index_dailybasic` 字段生成B3月度历史文件：两只指数从2015-01-01至最近完整月末各请求一次，每个自然月末只选择当月最新共同交易日，禁止跨月沿用。历史点采用 `releaseDate=periodDate` 的收盘后EOD语义，并标记 `revisionStatus=not_tracked`；接口任一返回达到3000行上限时失败关闭。

## B1 ERP股权风险溢价——第一阶段指数盈利收益率代理

- 来源：复用B3/B5同一份 Tushare Pro `index_dailybasic` 共同快照及其 `pe_ttm`，不增加API请求。
- 公式：`earnings yield = 100 / PE_TTM`。
- 范围：沪深300与创业板指；`period/release` 与B3/B5严格相同。
- 校验：PE TTM必须为有限正数；零、负数或非法值使整次生成失败，不回退旧日期。

当前尚未接入中国长期无风险利率，所以B1展示的只是股权端指数盈利收益率代理，不是ERP；不计算历史分位、趋势或评分。

阶段04B的B1月度历史没有新增数据源或网络请求，完全从B3历史的Tushare `index_dailybasic` PE TTM按 `100 / peTtm` 派生，并原样继承日期与 `revisionStatus=not_tracked`。

## B2 股息率－无风险利率——第一阶段股息率端代理

- 来源：复用B4的同一次 Tushare Pro `daily_basic` 请求，不增加API调用；字段合并为 `ts_code,trade_date,total_mv,dv_ttm`。
- 日期：严格复用B1/B3/B4/B5共同交易日。
- 有值样本：`dv_ttm` 的空值不视为0并排除；有限且非负的数值为有效样本，其中0是合法观测。
- 计算：`sum(total_mv × dv_ttm) / sum(有值样本 total_mv)`；同时披露有值股票数、有值样本市值和相对B4当日总市值的覆盖率。
- 失败边界：全部缺失，或任一非空 `dv_ttm` 为负数、非数值或无穷值时，整次生成失败。

当前尚未接入中国长期无风险利率，所以B2只是A股有值样本市值加权TTM股息率代理，不是“股息率－无风险利率”；不计算历史分位、趋势或评分。

阶段04D的B2月度历史继续使用当前已有的 Tushare Pro `daily_basic` API，字段严格为 `ts_code,trade_date,total_mv,dv_ttm`；`dv_ttm` 是TTM股息率，`total_mv` 单位为万元，单次最多6000条。每月只按B3指定的 `periodDate` 请求一次全A截面，空股息率不当作0；历史仍没有无风险利率，因此不是完整B2。

## B4 总市值/GDP——第一阶段A股当日总市值代理

- 提供方/API：Tushare Pro `daily_basic`，与B2共享一次请求，字段严格为 `ts_code,trade_date,total_mv,dv_ttm`；`total_mv` 单位为万元。
- 日期：严格复用B1/B3/B5共同交易日，只请求 `trade_date=snapshot.tradeDate`，失败时不回退日期。
- 计算：对本次返回且通过校验的每条股票记录直接求和，再除以100,000,000换算为万亿元；不逐行四舍五入。
- 完整性保护：空结果、混入其他日期、股票代码缺失或重复、任一 `total_mv` 非正或非法均失败；返回达到6000条接口上限时按可能截断处理并失败关闭。

当前股票数只是本次 `daily_basic` 实际有效记录数，不能冒充上市公司总数。系统尚未接入GDP分母，也未证明停牌或缺失股票全部覆盖，因此B4不是总市值/GDP或巴菲特指标，不计算历史分位、趋势或评分。

阶段04E的B4月度历史没有新增数据源或网络请求，完全从04D已验证的B2历史逐点继承 `stockCount` 与 `totalMarketCapWan`；底层仍是 Tushare Pro `daily_basic.total_mv`。历史仅增加从万元到万亿元的确定性单位换算，没有GDP分母，仍不是完整B4。

## B5 投机热度——第一阶段交易活跃度代理

- 提供方：Tushare Pro
- API：`index_dailybasic`
- 指数：沪深300 `000300.SH`、创业板指 `399006.SZ`
- 字段：`trade_date,turnover_rate,turnover_rate_f`
- 算法：复用B3的最近共同交易日快照，展示两只指数的换手率、自由流通换手率，以及“创业板指自由流通换手率 / 沪深300自由流通换手率”的描述性比值。

Tushare在 `index_dailybasic` 中将 `turnover_rate` 定义为换手率、`turnover_rate_f` 定义为基于自由流通股本的换手率。目前B5只是两类指数的真实换手率代理，不是完整投机热度指标；未接入全市场涨跌停、市场宽度、成交集中度和历史分位，因此不评分、不判断高温或低温。

阶段04C的B5月度历史仍使用现有 `index_dailybasic`，没有新增API种类；历史请求字段为 `ts_code,trade_date,turnover_rate,turnover_rate_f`。其日期严格继承B3月度PIT日程，B3指定日期缺少任一指数记录时失败，禁止寻找邻近日或回退。历史同样只保存换手率原值与确定性比值，不评分、不判断投机冷热。

## L2 M1/M2货币活化

- 结构化数值：Tushare Pro `cn_m`，字段 `month,m1_yoy,m2_yoy`。
- 发布日期证据：中国人民银行“调查统计司 → 数据解读”固定栏目 `https://www.pbc.gov.cn/diaochatongjisi/116219/116225/index.html`。
- 官方值交叉验证：该栏目直接列出的金融统计数据报告正文。
- 计算：`M1同比 - M2同比`，单位为百分点（pct）。
- 一致性门槛：PBOC正文与Tushare的M1、M2各自差异均不得超过0.05个百分点；否则整次生成失败。

PBOC列表标题只接受明确的普通月、一季度、上半年、前三季度和年度金融统计数据报告。文章URL必须位于固定栏目路径，列表日期必须与文章发布时间的自然日一致。`cn_schedule`实际返回未覆盖`cn_m`，任务03B不再把它作为L2发布日期证据，也不根据数据月猜发布日期。

自2025年1月统计数据起，M1采用修订口径。本轮不拼接新旧历史序列，不建立长期标准化，也不重算历史M1。

## L3 信用脉冲——第一阶段社会融资规模代理

- PBOC：中国人民银行同一份“金融统计数据报告”，解析社会融资规模存量、存量同比、社会融资规模增量累计和官方发布时间。
- Tushare Pro：`sf_month`，字段严格为 `month,inc_month,inc_cumval,stk_endval`。
- 目标月：`month` 必须与报告标题解析出的数据月完全一致且恰好一条，不回退到邻月。
- 双源校验：PBOC与Tushare的存量、累计增量分别比较；累计增量先从亿元除以10000换算为万亿元，两项差异均不得超过0.005万亿元。
- 展示：Tushare当月增量、累计增量和存量，加上PBOC存量同比；`period/release` 与L2完全相同。

L3当前只是全国社会融资规模的信用规模代理，不是完整 `credit impulse`。本轮不计算历史增量变化、不做名义GDP归一化或滚动标准化，也不评分或判断信用方向。L2与L3复用同一次PBOC正文抓取，不为L3增加第二次PBOC请求。

## L4 财政脉冲——第一阶段财政收支规模代理

- 提供方：中华人民共和国财政部。
- 固定栏目：`https://gks.mof.gov.cn/tongjishuju/`，只读取当前首页，不使用搜索或历史分页。
- 标题：只接受 `YYYY年1-N月/一季度/上半年/前三季度/全年财政收支情况` 的精确模式，并映射为数据月。
- URL：只允许 `https://gks.mof.gov.cn/tongjishuju/` 下以 `.htm` 结尾的首页实际链接；所有重定向失败关闭。
- 验证：文章标题必须与首页一致，文章“发布日期”必须等于首页条目日期。
- 字段：全国一般公共预算累计收入、累计支出及各自同比；收入和支出从亿元换算为万亿元展示。

L4当前只表示财政收支规模，不是完整财政脉冲；不计算支出减收入作为“赤字”，不合并政府性基金，不做GDP归一化、历史边际变化、滚动标准化、趋势或评分。

## L5 外部金融条件——第一阶段美国实际利率代理

- 提供方：Tushare Pro
- API：`us_trycr`
- 字段：`date,y10`
- 日期：在30个自然日窗口中选择严格早于中国EOD `asOf` 的最近唯一合法美国数据日，以避免使用尚未完整形成的美国同日数据。
- 数值：美国10年期实际国债收益率，允许有限负值。

L5当前只是美国10年实际国债收益率单变量代理，不是完整金融条件指数；未接入美元、波动率、信用利差、汇率或全球流动性，也不做方向判断或评分。当前仅实施自然日级跨时区保守边界，不处理精确小时级PIT。

## 安全与失败边界

Token只从 `process.env.TUSHARE_TOKEN` 读取，不写入代码、日志或JSON。财政部、PBOC或Tushare任一步失败，或官方文章身份、日期、目标字段及现有数值验证任一失败时，生成器非零退出；正式文件只在全部验证通过后由临时文件原子替换。
