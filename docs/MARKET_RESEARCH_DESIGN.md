## 1. 产品定位

市场研究不输出一个“牛市概率”，而是同时回答三个彼此独立的问题：

| 类比 | 一级状态 | 代码 | 回答的问题 | 分数方向 |
| --- | --- | --- | --- | --- |
| 发动机 | 长牛底座 | F / Foundation | 市场是否具备持续 5–10 年的长期基础？ | 越高越好 |
| 汽油 | 货币信用 | L / Liquidity | 未来 6–24 个月，金融条件是在支持还是约束资产？ | 越高越有利 |
| 转速表 | 估值泡沫 | B / Bubble | 股票是否昂贵、拥挤或进入投机红线？ | 越高越危险 |

制度与政策以 `policy_overlay` 单列，保持定性，不进入三表总分。市场研究是总体仓位系统的上游输入，不是独立交易指令，也不直接给出精确实盘仓位。

## 2. 页面信息架构

全站采用顶部主导航与全宽工作区，不使用左侧栏。正文基础字号不低于 12px，常规说明文字以 13–14px 为主，确保桌面端远距离阅读和高信息密度兼顾。

市场研究内部固定为四个二级页面：

1. **总览**：当前诊断、F/L/B 三卡、政策叠加、联合状态、驱动与风险、证据摘要、近期历史和关键事件。
2. **历史诊断**：沪深300与 F/L/B 月度序列、状态区间、关键事件；支持系列显隐。
3. **关键时期审计**：2005–2007、2007–2008、2008–2009、2014–2015、2017–2018、2019–2021、2021–2022、2024–当前。
4. **方法与数据**：三表方法、14项指标字典、评分方法、Point-in-Time、数据质量与已知限制。

桌面端总览首屏顺序固定为：

`当前诊断 → F/L/B 三卡 → Policy Overlay → 联合状态 → 驱动与风险 → 证据摘要 → 近期历史变化 → 关键事件`

## 3. 总览组件规格

### 3.1 当前诊断

- 使用“状态 + 证据 + 投资含义 + 风险”的陈述结构。
- 表达仓位倾向或风险预算方向，不给精确仓位。
- 当前真实数据显式标注“真实快照 / 真实数据”；历史静态曲线和其他示例内容继续标注“示例”。
- 展示数据日期、数据覆盖率与质量等级；严重缺失或 PIT 问题显示 Warning。

### 3.2 F/L/B 一级卡

顺序为 F → L → B，对应先看发动机、再看汽油、最后看转速表。每张卡首屏只显示：

- 分数与状态带；
- 数据覆盖率、数据期和更新时间；
- 最近12个月迷你趋势；
- 两个最重要正向驱动；
- 一个主要风险；
- 展开指标详情入口。

展开区显示子指标的名称、得分、状态、原始值、历史位置、趋势、数据期、发布日期、覆盖率、质量和一句解释。使用页面内展开，不使用全屏弹窗。

### 3.3 Policy Overlay

- 显示 `supportive / neutral / restrictive`，未来可映射 `-2 ~ +2`。
- 展示 2–4 条定性原因。
- 不并入 F/L/B，不参加第一阶段量化回测。

### 3.4 联合状态

保留 F/B/L 二分后的八种标准状态，但允许当前状态显示为“由 A 向 B 过渡”，不强行制造精确边界：

| F | B | L | 状态含义 |
| --- | --- | --- | --- |
| 高 | 低 | 高 | 黄金牛市环境 |
| 高 | 高 | 高 | 牛市后期 / 过热 |
| 高 | 低 | 低 | 长牛中的调整 |
| 高 | 高 | 低 | 高度危险 |
| 低 | 低 | 高 | 流动性 / 政策牛 |
| 低 | 高 | 高 | 投机牛 |
| 低 | 低 | 低 | 熊市底部寻找阶段 |
| 低 | 高 | 低 | 最差状态 |

八张状态卡中突出当前状态与演变方向，并说明驱动、投资含义与主要风险。

### 3.5 原有模块归属

- “市场状态雷达”退出一级核心布局，由 F/L/B 三表取代。
- “估值水位”归入 B 估值泡沫体系。
- “市场宽度”降为 B5 投机热度 / 参与度的证据。
- “资金方向”拆为长期资金 F4、交易资金 B5 和信用资金 L。
- “关键事件”保留；首屏只展示最近事件，完整内容进入历史时间轴，制度事件同时服务 Policy Overlay。

## 4. 历史与可信度设计

- 历史诊断预留指数、F/L/B 四条时间序列、状态背景带及事件标记。
- 关键时期审计不是预测顶部日期，而是验证不同市场机制能否被正确解释。
- 数据质量是一级产品概念，展示 coverage、quality grade、发布日期与 PIT 状态。
- 方法与数据页必须解释 `period_date`、`release_date`、财报公告日、宏观发布时间、M1口径变化、历史数据修订、退市股票与幸存者偏差。
- 禁止使用未经校准的“95%置信度”等措辞。

## 5. 颜色与交互

- 绿色：健康 / 支持；黄色：中性 / 温热 / 过渡；红色：风险 / 恶化；灰色：缺失 / 不可判断；蓝色：信息与交互。
- 二级页面状态写入 URL，支持刷新、收藏和未来深链接。
- 为 Loading、Empty、Partial Coverage、Warning 预留统一状态组件。
- 专业指标提供解释入口；总览不直接铺满14项指标。

## 7. 实施共识

- 保持 F、L、B 三个一级分数独立，禁止合成为牛市概率。
- Policy Overlay 单列，不计入三表量化总分。
- F/L/B 合计预留14项量化指标；字段遵循数据字典。
- 实现总览、历史诊断、关键时期审计、方法与数据四个二级页面。
- 总览显示数据质量摘要；严重缺失或 PIT 问题显式警告。
- F1–F4、L1–L5、B1–B5全部标注“真实快照 / 真实数据”；历史静态曲线和其他示例内容继续标注“示例”。
- 当前市场状态只允许来自 `current.json`；读取失败时显式报错，不回退 TypeScript Mock。
- 仓位只表达倾向，明确市场研究是仓位系统上游而非交易指令。

### SHOULD

- F/L/B 卡页面内展开指标详情。
- 联合状态用八张状态卡呈现，突出当前状态和演变方向。
- 历史诊断支持系列显隐与关键时期跳转。
- 首页每张卡只显示两个正向驱动和一个风险。
- 最近12个月迷你趋势帮助判断改善或恶化。
